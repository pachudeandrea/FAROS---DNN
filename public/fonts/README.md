# Basis Grotesque Arabic Pro

Full WOFF2 files supplied by the user in `basis-grotesque-arabic-pro.zip`.
Only the manual’s Light (300), Regular (400) and Bold (700) weights are served.
Black, Medium, EOT, TTF and demo HTML from the archive are not needed by the app.

The supplied TTF metadata identifies Colophon Foundry and points to its license
at www.colophon-foundry.org. The ZIP contains no separate license document.
No license terms are inferred or changed by this integration.

The CSS family is Basis Grotesque Arabic Pro. `/brand/tokens.css` serves the
provided WOFF2 locally with font-display: swap and a system fallback for loading
or failure. All three complete source fonts contain 858 mapped characters,
including Spanish accents, ñ, ¿, ¡, financial punctuation and the euro symbol.
No embedded PDF subset is used as a web font.
