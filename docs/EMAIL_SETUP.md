# Recuperación de cuenta

La recuperación usa el código de 4 dígitos que cada usuario elige al registrarse o configura desde Cuenta y Privacidad. El flujo actual no envía correos ni necesita un proveedor de envío.

Los pasos de configuración, uso, seguridad y despliegue están en [ACCOUNT_RECOVERY.md](ACCOUNT_RECOVERY.md).
